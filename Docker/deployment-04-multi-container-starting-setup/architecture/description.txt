ECS(Elastic Container Service)
- Cluster 안에 여러 개의 Service, 각 Service 안에 여러 개의 Task, 각 Task 안에 여러 개의 Container가 있는 형태
ECS의 Fargate모드는 각 서비스를 서버리스(serverless)로 실행할 수 있음
- EC2모드는 특정 용량의 EC2 서버 인스턴스를 생성해야 함 
- Fargate는 AWS가 필요한 리소스를 자동 할당 함
서비스에 Load Balancer를 추가하면 
- 자동 트래픽 분산
- 일정 시간 마다 서버 체크(Health Check)
- 서비스 업데이트할 때마다 ip 바뀌어서 불편한데, 도메인 지정 가능
- Load Balancer를 생성할 때 Target Group의 VPC와 서비스의 VPC가 동일해야 함
데이터베이스 persistance를 위해 TASK의 mongo 컨테이너에 볼륨을 생성하고 이름과 Path 지정
- 해당 이름의 볼륨을 file system id를 EFS(Elastic File System)로 지정하면(EFS 연결) 스토리지 용량이 탄력적으로 축소/증가
- EFS의 네트워크에 서비스와 같은 Security Group을 추가해야 함
